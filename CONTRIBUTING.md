# Contributing

Issue reports, security reports, reproducible test cases, and product feedback are welcome through the repository's standard forms. Report vulnerabilities privately as described in `SECURITY.md`.

Do not submit pull requests containing code or documentation until the project publishes its contributor agreement. The community and commercial dual-license model requires an explicit, documented grant of rights from every contributor; accepting patches without that agreement could prevent consistent licensing later.

Maintainers may close unsolicited code contributions without merging them. This policy will be replaced when the contributor agreement and intake workflow are ready.
